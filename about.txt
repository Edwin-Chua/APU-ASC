PROJECT: APU Automotive Service Centre (APU-ASC)
Java Swing GUI application. No database — all data stored in .txt files.
Window size: 1200x800. Single JFrame, CardLayout for role switching.

KEY OOP PATTERNS USED
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- Inheritance:    Manager/Customer/etc. extend User
                  All dashboards extend BaseDashboard
- Abstraction:    BaseDashboard declares abstract createSidebar(),
                  createContentPanel(), refreshUser()
- Encapsulation:  All entity fields private, accessed via getters/setters
- Shared UI:      AppTheme (design tokens) + UIComponent (component factory)
                  used across all views — no hardcoded colors/fonts
- Error handling:  try-with-resources / try-catch for file I/O in DAOs;
                     user-facing messages via JOptionPane where appropriate

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
DATA LAYER NOTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- No database. All persistence via .txt files (CSV-style).
- Each DAO handles one .txt file (except UserDAO which handles all 4 role files).
- UserDAO.loginUser(email, password) searches all 4 role files,
  returns the correct User subtype (Manager, Customer, etc.)
- Billing = invoice (what is owed). Payment = transaction (how it was paid).
  One Billing links to one Payment.

SHARED UI SYSTEM (views/shared/)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
AppTheme.java  — single source of truth for all visual tokens:
  colors (brand, background, sidebar, text, border)
  fonts (headings h1–h4, body, small, label, sidebar)
  dimensions (field size, button size, sidebar width, header height)

UIComponent.java    — static factory methods for all reusable components:
  createPrimaryButton(text)
  createOutlineButton(text)
  createCard()
  createTextField(placeholder)
  createPasswordField()
  createFieldLabel(text)
  createSidebarButton(text)
  (+ any others needed per role)

BaseDashboard.java — abstract JPanel:
  All 4 role dashboards extend this.
  Constructor calls createSidebar() + createContentPanel() automatically.
  refreshUser() is called by MainFrame after every showPage() to push
  the logged-in user's data into the dashboard labels.
